# UniSign | سامانه حضور و غیاب دانشگاه

UniSign یک برنامهٔ تحت وب مبتنی بر Django برای مدیریت اطلاعات آموزشی و ثبت حضور و امضای دانشجویان است. پنل مدیریت و رابط کاربری برنامه عمدتاً فارسی هستند.

## قابلیت‌ها

- مدیریت استادان، دانشجویان، درس‌ها و ترم‌ها
- ثبت ارتباط دانشجو با درس (انتخاب واحد) و اطلاعات حضور و امضا
- واردکردن اطلاعات از فایل Excel
- بارگذاری PDF و استخراج اطلاعات دانشجویان و تصاویر موجود در فایل
- ثبت و مشاهدهٔ امضای دانشجو برای هر درس
- نمایش تاریخ‌ها با تقویم شمسی
- API برای ورود، جست‌وجو و دریافت اطلاعات درس‌ها، دانشجویان، آمار و امضا با JWT

## پیش‌نیازها

- Python سازگار با نسخه‌های بسته‌های `requirements.txt`؛ نسخهٔ Python در این مخزن pin نشده است.
- MySQL Server، مانند MySQL همراه WAMP
- pip برای نصب وابستگی‌های Python

وابستگی اصلی پروژه `Django==5.2` است. بستهٔ قدیمی `django-jalali-date==2.0.0` از `distutils` استفاده می‌کند؛ از Python 3.12 به بعد `distutils` در خود Python وجود ندارد. بنابراین برای همین مجموعهٔ وابستگی‌ها Python 3.11 گزینهٔ عملی‌تری است. Python 3.15 در این مخزن آزموده نشده و برای استفاده از آن باید وابستگی‌های ناسازگار به‌روزرسانی یا جایگزین شوند.

## نصب و اجرا در ویندوز

PowerShell را در پوشهٔ پروژه باز کنید و محیط مجازی را بسازید:

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

اگر فعال‌سازی در PowerShell مسدود بود، می‌توانید به‌جای `python` از مسیر `.\.venv\Scripts\python.exe` برای اجرای دستورات پروژه استفاده کنید.

## پیکربندی پایگاه‌داده

1. سرویس MySQL را روشن کنید و یک پایگاه‌داده بسازید؛ برای مثال:

   ```sql
   CREATE DATABASE university CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

2. مقدارهای `ENGINE`، `NAME`، `USER`، `PASSWORD`، `HOST` و `PORT` را در بخش `DATABASES` فایل `unisign/settings.py` با MySQL محلی خود هماهنگ کنید. مقادیر فعلی فایل برای محیط شخصی شما مناسب نیستند.
3. از ریشهٔ پروژه، هر دستور را جداگانه اجرا کنید:

   ```powershell
   python manage.py check
   python manage.py migrate
   python manage.py createsuperuser
   ```

`migrate` جدول‌های برنامه را ایجاد می‌کند؛ لازم نیست آن‌ها را دستی بسازید. `createsuperuser` را فقط برای ساخت حساب مدیر اجرا کنید و اگر حساب دارید از این مرحله بگذرید.

سرور توسعه را اجرا کنید:

```powershell
python manage.py runserver
```

در مرورگر به <http://127.0.0.1:8000/admin/> بروید و با حساب مدیر وارد شوید. مسیر `/` نیز به پنل مدیریت هدایت می‌شود. برای متوقف‌کردن سرور در PowerShell، `Ctrl+C` را بزنید.

## بارگذاری فایل‌ها

پس از ورود به پنل مدیریت، بخش درس‌ها را باز کنید. صفحه‌های **آپلود Excel** و **آپلود PDF** از همان بخش در دسترس‌اند. مسیرهای مستقیم آن‌ها به‌ترتیب `/admin/unisign/course/upload-excel/` و `/admin/unisign/course/upload-pdf/` هستند.

## API

مسیرهای اصلی تعریف‌شده در پروژه:

| مسیر | کاربرد |
| --- | --- |
| `POST /api/login/` | ورود و دریافت توکن JWT |
| `GET /api/courses/exam-dates/` | دریافت درس‌ها و تاریخ آزمون |
| `GET /api/statistics/overall/` | دریافت آمار کلی |
| `GET /api/courses/<course_id>/students/` | دریافت دانشجویان یک درس |
| `POST /api/students/<student_id>/signature/<course_id>/` | ثبت یا به‌روزرسانی تصویر امضای دانشجو برای درس |
| `GET /api/courses/search/` | جست‌وجوی درس‌ها |

برای endpointهایی که احراز هویت می‌خواهند، توکن را در هدر `Authorization: Bearer <token>` بفرستید. جزئیات روش و پارامترهای هر endpoint در پیاده‌سازی `unisign/api_views.py` قرار دارد.

## امنیت پیش از انتشار در GitHub

**تنظیمات فعلی را بدون بازبینی در مخزن عمومی منتشر نکنید.** فایل `unisign/settings.py` در حال حاضر کلید Django، اطلاعات اتصال MySQL و توکن API را به‌صورت ثابت نگه می‌دارد. اگر این مقادیر واقعی یا قبلاً در دسترس دیگران بوده‌اند، آن‌ها را تعویض/باطل کنید؛ سپس از کد خارج کرده و با متغیرهای محیطی یا تنظیم محلیِ خارج از Git جایگزین کنید. پیکربندی فعلی به‌طور خودکار این متغیرها را نمی‌خواند و باید جداگانه امن‌سازی شود. همچنین `DEBUG` روشن و `ALLOWED_HOSTS` برای توسعه باز تنظیم شده‌اند؛ این تنظیم‌ها برای استقرار عمومی مناسب نیستند.

## ساختار پروژه

```text
manage.py          ابزار مدیریت Django
requirements.txt   وابستگی‌های Python
unisign/           تنظیمات، مدل‌ها، پنل مدیریت، viewها و API
templates/         قالب‌های HTML
static/            فایل‌های استاتیک برنامه
staticfiles/       مقصد جمع‌آوری فایل‌های استاتیک
media/             فایل‌های بارگذاری‌شده
```
